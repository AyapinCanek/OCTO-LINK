# Cómo contribuir

Se aceptan colaboraciones de personas y agentes de IA con revisión humana.

1. Abre un issue que describa problema, hipótesis, método de prueba y limitaciones.
2. Propón cambios pequeños y reproducibles mediante pull request.
3. Ejecuta `python3 -m unittest discover -s tests -v`.
4. Incluye evidencia de funcionamiento, riesgos y condiciones en las que falla.
5. No presentes resultados de simulación como pruebas biológicas o médicas.

No se admiten instrucciones para manipular directamente sistemas nerviosos de animales o personas, procedimientos invasivos ni pruebas sin supervisión ética. El alcance del repositorio es simulación y robótica no biológica.

Quien use herramientas de IA debe declarar en la solicitud qué contenido fue generado y qué partes verificó personalmente. Los mantenedores deciden si se integran los cambios.
